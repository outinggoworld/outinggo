Frontend mein Payment Button Add Karo

Website ke booking form mein yeh script add karo (closing </body> se pehle):

<script src="https://checkout.razorpay.com/v1/checkout.js"></script>

async function payNow(bookingId, amount, name, phone) {
  // 1. Backend se order create karo
  const res = await fetch('/api/payment/create-order', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({amount, bookingId, name, phone})
  });
  const {orderId, key} = await res.json();

  // 2. Razorpay popup open karo
  const rzp = new Razorpay({
    key, order_id: orderId,
    name: 'Outingo', description: 'Outing Booking',
    prefill: {name, contact: phone},
    theme: {color: '#22c55e'},
    handler: async (response) => {
      // 3. Payment verify karo
      await fetch('/api/payment/verify', {
        method: 'POST',
        body: JSON.stringify({...response, bookingId})
      });
      alert('✅ Payment successful! WhatsApp confirmation coming!');
    }
  });
  rzp.open();
}
✅ Test mein card number use karo: 4111 1111 1111 1111, CVV: 123, Expiry: any future date

Frontend Deploy — Netlify (FREE)

HTML website ke liye sabse easy:

  • 1. Jao netlify.com → Sign up
  • 2. outingo.html file drag & drop karo
  • 3. Site Settings → Custom Domain → outingo.in add karo

# Ya Netlify CLI se deploy karo:
npm install -g netlify-cli
netlify deploy --prod --dir=.
C

Backend Deploy — Render.com (FREE)

  • 1. GitHub pe outingo-backend push karo
  • 2. render.com → New Web Service
  • 3. GitHub repo connect karo
  • 4. Build Command: npm install
  • 5. Start Command: npm start
  • 6. Environment Variables add karo (.env ki values)
  • 7. Deploy! URL milegi: outingo-api.onrender.com
✅ Render free tier: 750 hrs/month — ek server ke liye kaafi hai!
⚠️ Free tier mein server 15 min baad sleep ho jata hai. Upgrade karo ₹700/month pe production ke liye.
